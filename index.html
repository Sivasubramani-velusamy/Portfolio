RESEARCH & PUBLICATIONS

Research

IEEE PUBLICATION · ICDCA 2026 · AUGUST 2026

HyperPart-DL: An Intelligent Hypergraph Based Deduplicated Storage System Using DL

Published in: 2026 International Conference on Data Science for Cyber-Physical Systems Resilience using Advanced Applications (ICDCA), IEEE Xplore

My role: Project Lead and Core Developer

HyperPart-DL models files, data chunks and storage nodes as a weighted hypergraph and uses a learning module to predict future block hotness and access frequency. These predictions guide data placement and incremental repartitioning, so only the necessary data blocks migrate when workloads shift. It was evaluated on synthetic and trace-based workloads.

30–55% reduction in access span
40% lower migration overhead
50%+ faster recovery from workload shifts
